# 私聊存档与模型列表获取（2026-11-07）

## 行为

- 新存档固定保留最近 30 个完整用户／角色互动回合，保存轮数独立于聊天请求上下文预算；不足时保存已有完整回合。
- 旧存档保持原文范围，读取确认和详情根据实际内容计算回合数量。
- 保存弹窗说明范围，列表区别“对话已保存／前情整理中／整理失败可重试／可读取”。
- 存档轮询只查询元数据，详情按需读取。大字段使用现有 Android 分块读取机制，不截断原文。
- 读档在数据库事务中保存当前历史、转存旧会话记忆及替换消息。旧记忆、向量及来源队列保留但退出当前剧情召回；关联推导结论也被隔离。干员全局长期印象不再因读档而删除。
- 读档期间取消会话后台维护；当前剧情的私聊召回按 session + timeline epoch 过滤，屏蔽其他进度长期印象和公开后续事件。

## 模型设置交互

- 厂商／地址 → API 密钥 → 模型 → 获取模型 → 搜索选择面板 → 测试聊天模型 → 保存。
- 不要求先保存输入或先填模型名。请求可取消，切换配置清理旧列表及测试状态，过期请求不得覆盖新结果。
- OpenAI 兼容列表使用同一路径前缀的 models 接口；Google 使用 models + 原生认证与分页，Anthropic 使用 models + 原生认证与分页，小米使用 api-key。
- 自定义基础地址的常见版本路径保存时规范为完整聊天地址，已有非标准完整地址及查询参数保留，避免改变现有手填配置。
- 网络重定向不跟随；响应大小、总耗时、分页数量和模型数量有上限。错误不展示原始服务端响应和密钥。
- 模型枚举只代表服务商返回列表，不能代替选中模型的聊天能力验证；获取失败保留所有填写内容和手填入口。

## 验证范围

单元测试覆盖轮次裁剪、旧存档范围、URL 推导及手填兼容、模型解析、认证、分页、防循环、错误与取消。Android 数据库测试覆盖读档保留、事务回滚和大字段元数据读取；模型面板测试覆盖搜索、完整 ID 选择及手填回退。

没有使用真实用户密钥逐家调用远端服务。是否支持模型枚举及具体模型权限，仍以各账号和服务商实际接口为准。
