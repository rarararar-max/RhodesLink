# 流光玻璃皮肤

新增独立 `liquid_glass` 外观，入口：我 → 外观设置 → 流光玻璃。沿用原有即时应用与持久化机制，默认皮肤不变。

## 实现范围

- 深蓝紫色柔光背景、透明面板、圆角轮廓、玻璃薄膜高光。
- 聊天、通讯录、设置、动态、日记、功能入口与外观设置适配。
- 聊天气泡保留高遮盖底色，输入栏采用圆角高光边框。
- 强调色浅蓝，强调按钮使用深色前景，正文与次级文字保持不透明。
- 所有绘制按布局尺寸缓存，无持续动画，无逐条聊天截图或实时背景采样。

## 兼容性边界

已检查 Kyant0/AndroidLiquidGlass（Backdrop）正式版本。1.0.0 要求 Kotlin 2.2.21 / Compose 1.9.4 / compileSdk 36；当前工程使用较早工具链。本次采用现有 Compose 框架内的兼容视觉实现，没有引入该库，没有实现该库的实时背景折射、色散或触摸形变，也未升级整个构建工具链。此皮肤通过半透明填充、柔光背景与边缘高光表现玻璃风格。不同 Android 版本采用同一绘制路径。

## 验证

- `:app:assembleDebug :app:assembleDebugAndroidTest` 离线构建。
