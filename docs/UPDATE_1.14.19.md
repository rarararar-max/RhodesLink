# 1.14.19 聊天交互修复

## 用户可见变化

- 移除群聊保存消息时短暂出现的发送提示，保留重复点击保护。
- 私聊、群聊的新AI气泡使用各自首次显示时间排序，后续气泡不会因属于同一轮回复而插到后来发送的用户消息前。首次显示时间复用已有显示事件表保存，退出重进仍可还原顺序。
- 兼容旧版的小序号显示事件：旧记录继续使用原消息时间，不猜测旧气泡的实际出现时间，不改写历史消息、ID或模型上下文。
- 主动上滑即停止自动跟随。右下角提供“↓ 最新消息”，期间有新消息时显示“↓ 新消息”；回到底部或主动发送后恢复跟随。
- 加载历史页时保留阅读位置；加载提示合并进固定头部，避免额外列表项造成索引偏移。搜索定位使用实际显示列表的顺序。
- 群聊保存成功只清空尚未编辑的本次草稿；上一轮回复结束后的回调不会干扰下一次发送。
- 图片保存前保留预览和配文。保存失败可直接重试；保存成功后恢复输入，后续识图失败保留已保存图片，避免反复恢复预览造成重复发送。
- 修正私聊图片界面的尾随lambda绑定错误，明确绑定保存结果，而非AI回复结束。保存结果仅回调一次，避免迟到的失败回调误改后续发送状态。
- 客服资料同步说明上述行为。

## 真机重点验收步骤

1. 私聊、群聊分别发送A，在AI分段展示时发送B，确认后续AI气泡出现在B之后；退出重进再检查。
2. 上滑查看历史，在AI继续回复、翻页加载、键盘弹出时检查阅读位置；点击右下角返回最新，确认重新跟随。
3. 发送后马上编辑输入框，确认新草稿不被保存回调清空；连续发送时检查旧回复完成不会重新启用正在保存的发送按钮。
4. 选择无法读取的图片，确认预览和配文仍在、可重新发送；图片已保存后断网，确认原图片保留且不会自动恢复为另一条待发图片。
5. 从相同签名的旧版直接覆盖安装，核对角色、聊天、动态、日记、知识库、余额、模型设置与备份导入导出。
