# DeepSeek ASR 与自动复用（1.14.31 / 78）

依据官方 https://api-docs.deepseek.com/zh-cn/guides/asr ，添加 HTTP multipart 文件识别；PCM 录音封装为单声道16位 WAV，Bearer 鉴权，不发送 model/language 参数；检查采样率、120秒、8 MiB，解析 text 并对错误码提供不含服务端敏感内容的提示。请求沿用可取消的功能级超时，不自动重复付费请求。

## 配置
- 新安装且没有 ASR 专属设置的用户默认自动模式；已有独立配置保持原样。
- DeepSeek 文本测试返回非空且用户保存后，记录同一受保护设置中的验证凭据；自动模式只对一致的服务商、Key、型号生效。凭据不加入可移植备份白名单、不打印日志。
- 识图沿用自动/独立设置，DeepSeek 自动识图增加同样验证门槛；旧用户未选择自动时不覆盖。
- 语音识别独立列表增加 DeepSeek；不显示无意义的模型名字段，支持测试音频上传。
- 私聊、群聊、陪睡、通话、DI 入口统一解析有效 ASR 配置。DI 在每次识别时读取，避免保存后仍用旧服务。
- 自动与独立分别保存；切换不会清空独立配置。不对手动配置失败静默降级。

## 验证范围
365项 JVM 测试通过，其中新增4项覆盖：自动配置验证及失效、旧配置优先、音频与返回边界、本地 HTTP 真实 multipart/WAV 请求往返。
本地协议测试不是 DeepSeek 官方服务真实识别：当前没有可用测试凭据，尚未完成官方账号的端到端语音/识图验证。用户可在设置中使用自有 Key 分别测试文本、识图、语音。
