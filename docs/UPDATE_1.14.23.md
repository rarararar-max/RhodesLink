# 1.14.23 泰拉见闻报

## 功能

功能页“干员日记”下方新增“泰拉见闻报”。独立报刊亭，现实新闻主题经DeepSeek转写为泰拉同人报道，仅面向用户阅读。不接入角色、聊天、人设、记忆、向量注入或既有自动生成任务。

第一版每个北京时间自然日一期、20龙门币。只在点击购买后联网；每天不会自动搜索，进页面不会自动制报。最多3次Search + 1次非流式模型请求，关闭思考，不默认逐篇Fetch，避免不必要成本。3次搜索按社会文化、科技工造、城市交通生活分组，过滤无日期、过期、重复及不安全链接，最多8条摘要交给模型。

生成四篇结构化报道：今日头条、世间百态、技术与工造、城际短讯；模型只给内容，Compose负责排版。校验标题、栏目、正文长度、来源ID、世界观改编标记。无资料不编造，不将用户资料送入API。提示词要求不把网页指令当指令、不冒充官方剧情、不引入知名角色、不把现实伤亡娱乐化。

标题层级、双分隔线报头、期号日期、栏目编号、阅读字号、正文选择复制、折叠来源和导出文本。所有页面主题使用现有BG/Surface/TextPrimary/Primary等响应式颜色；终端皮肤使用现有切角形状。没有硬编码米白背景/黑色字导致夜间失配。

## 配置与费用

仅支持DeepSeek官方。使用官方DeepSeek聊天配置可复用密钥；其它聊天厂商或中转使用报纸专用密钥，只保存在现有设置后端，不改变聊天配置。密钥固定发往api.deepseek.com，不跟随HTTP跳转，错误日志不输出密钥或原始响应。

保存设置不触发请求。API验证在购买时执行，没有额外连接测试开销。应用进程内制报不随退出页面取消；进程被系统终止后不自动重试。搜索成功后按步骤缓存两小时，失败后的手动重试复用已完成步骤。用户可显式勾选当日与前一日资讯，不静默扩大范围。

成品采用AtomicFile持久化，之后在同一个settings提交中写已购标记与钱包扣币。提交失败成品保留，下次手动完成购买无需重新生成。同日已购直接读取，不重复扣币。并发点击用进程级单实例与原子锁保护。生成期间余额被其它功能花掉时不产生负数，保留待购买成品。

## 升级与边界

versionName1.14.23/versionCode70，applicationId不变。未修改SQL表、查询、迁移；既有记录不扫描、不清理。增加newspaper专用设置键和files/newspapers文件夹；原有皮肤与模型设置不变。

第一版馆藏不接入原有备份格式，避免在本次功能中扩大旧存档迁移范围。界面明确提示可导出本期正文与来源，不能将此视为完整机器迁移备份。卸载会丢失本地馆藏；覆盖安装保留文件。

新闻日期基于搜索提供的发布时间，不能保证来源元数据绝无错误。内容质量与世界观一致性受模型影响，不承诺每次生成完全符合官方背景。来源引用可查，报道明确同人属性。
