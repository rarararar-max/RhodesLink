# 1.14.17 AI客服专项更新

## 修复
- 清空/取消/切换客服时取消请求并使旧请求代号失效，防止旧回答回写。
- 红包发布与每日预算、领取与余额/已领取记录使用同一原有设置存储的一次同步提交；重复领取用原记录比较保护。旧记录兼容，新字段均有默认值。
- 普通文字承诺不再绕过本轮红包发放机会；未发放则明确以红包卡片为准。龙门币注明为应用内虚拟积分。
- 图片解码转移到后台线程；图片识别45秒预算，安全错误提示与文字请求分开。
- 客服持久化不再截断100条，界面分批加载；无法恢复旧版已经丢弃且无备份的记录。
- 追问结合最近用户问题主题检索；错误消息不作为客服回答发送到后续上下文。
- 失败问题可恢复至输入框，用户确认后再发送；回复可展开程序检索来源，历史版本不伪装成新版。
- 新增本机配置摘要预览，仅含厂商标识、是否填写模型/密钥、开关与识图可用性；不含密钥、接口、聊天、日志。预览后填入输入框，再手动发送。
- 手册同步自动识图、摘要/记忆修复、知识库部分可用、动态任务、日志计数、升级备份及客服红包。

## 数据兼容与验收边界
包名/签名不变，versionCode64；未改数据库表结构。不清空角色、聊天、知识库、余额或客服记录；不重新发放旧红包。旧红包保留原领取状态。后台配置摘要不是服务商验证。说明更新可能使已启用第三方向量检索的客服重新要求索引确认，不会未经确认自动重建付费索引。
